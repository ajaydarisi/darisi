# SEO Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove verified indexing conflicts and inert SEO code, then add a build-backed regression check for every public page.

**Architecture:** SEO remains metadata-first: `src/lib/seo.ts` supplies shared defaults, while blog routes own their Open Graph overrides. A static-output test will validate the files crawlers consume, and `npm test` will build the export first so it cannot inspect stale HTML.

**Tech Stack:** Next.js 16 App Router static export, TypeScript, Node's built-in test runner.

## Global Constraints

- Do not invent article publication times or article-specific images; the repository only records truthful dates and has no per-article artwork.
- Keep all existing canonical URLs, sitemap entries, RSS discovery, JSON-LD entity IDs, and RSC crawl exclusion.
- Do not add dependencies.
